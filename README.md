# 기후행동365 학교 환경 모니터링 대시보드

당곡고등학교 16개 교실의 환경 데이터(온도·습도·조도·미세먼지 등)를 실시간 수집·시각화하고, 학생이 데이터 기반 환경 개선 활동을 주도하는 시스템.

- **참여 학교:** 당곡고등학교 (서울)
- **활동:** 기후행동365
- **운영:** 학생 3개 팀 (조립 / 분석 / 운영)
- **작성:** 석리송 (당곡고 정보교사)
- **작성일:** 2026-05-21

## 폴더 구조

```
climate-action-365/
├── README.md          # 본 문서 (프로젝트 개요)
├── PLAN.md            # 현재 계획 (의사결정 기록)
├── PROGRESS.md        # 진행 상황 추적
├── PROJECT_BRIEF.md   # 사용자 원본 계획서
├── docs/              # 작성 문서 (BOM, 아키텍처, 매뉴얼 등)
├── reference/         # 리서치 결과 (센서 비교, 가격 조사 등)
└── prototype/         # 프로토타입 코드
    ├── firmware/      # Pico MicroPython
    ├── server/        # 데이터 수집 서버
    └── dashboard/     # 대시보드
```

## 측정 항목

필수: 온도, 습도, 조도, 미세먼지(PM1.0/2.5/10)
권장: CO2, TVOC

## 하드웨어

- Raspberry Pi Pico 2 WH × 16
- Grove Shield for Pi Pico × 16
- WiFi (학교 무선망)
- USB 5V 상시 전원

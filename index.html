기후행동365 · 교실 환경 모니터링

16개 교실, 한 자리에서 — 학생이 만들고 운영하는 환경 데이터 시스템
교재 소개부터 보기 Unit 1부터 시작

이 교재가 다루는 것

당곡고등학교 16개 교실의 환경 데이터(온도·습도·조도, 추후 CO2·미세먼지)를 실시간으로 수집·시각화하는 IoT 시스템을, 학생이 직접 만들고 운영하는 한 학기 분량의 자료입니다. Raspberry Pi Pico 2 WH와 마이크로파이썬으로 노드 16대를 조립하고, 라즈베리 파이 4를 서버로 두어 학교 내부망에서만 열리는 대시보드까지 한 호흡에 만듭니다.

Unit 1. 파일럿 한 대

펌웨어·Thonny·배선·검증까지. 16대 작업 전 반드시 한 대로 ‘인과 사슬’을 손에 익힙니다.

Unit 2. 서버 구축

라즈베리 파이 4에 systemd 자동 시작과 cron 백업을 박아 두어 ‘잊고 살 수 있는 시스템’으로 만듭니다.

Unit 3. 16대 조립

secrets.py 자동 생성·mpremote 일괄 배포·페어 워크 표준 절차로 16대를 한 번에 만듭니다.

Unit 4. 운영·장애

일일·주간·월간 점검의 세 시간 단위와 30분 복구 절차로 1년 운영을 설계합니다.

네 가지 리터러시

이 교재의 모든 단원에는 ‘🌟 리터러시 모먼트’ 박스가 단원당 2~4개씩 들어 있습니다.

  • 🧠 컴퓨팅 사고력 — 분해·표준 절차·자동화·인과 사슬
  • 🔬 과학적 사고력 — 가설 → 측정 → 비교 (학교보건법 기준)
  • 🤖 AI 리터러시 — 셸 메시지·SQL·매뉴얼 갱신에 챗 LLM 사용
  • 📊 데이터 리터러시 — 한 점의 측정값이 1년의 환기 정책으로

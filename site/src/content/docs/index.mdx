## 이 교재가 다루는 것

당곡고등학교 16개 교실의 환경 데이터(온도·습도·조도, 추후 CO2·미세먼지)를 실시간으로 수집·시각화하는 IoT 시스템을, **학생이 직접 만들고 운영하는 한 학기 분량**의 자료입니다. Raspberry Pi Pico 2 WH와 마이크로파이썬으로 노드 16대를 조립하고, 라즈베리 파이 4를 서버로 두어 학교 내부망에서만 열리는 대시보드까지 한 호흡에 만듭니다.

## 네 가지 리터러시

이 교재의 모든 단원에는 ‘🌟 리터러시 모먼트’ 박스가 단원당 2~4개씩 들어 있습니다.

- 🧠 **컴퓨팅 사고력** — 분해·표준 절차·자동화·인과 사슬
- 🔬 **과학적 사고력** — 가설 → 측정 → 비교 (학교보건법 기준)
- 🤖 **AI 리터러시** — 셸 메시지·SQL·매뉴얼 갱신에 챗 LLM 사용
- 📊 **데이터 리터러시** — 한 점의 측정값이 1년의 환기 정책으로

## 한 학기 운영 흐름

```
[1주]  오리엔테이션·팀 모집
[2주]  부품 발주
[3·4주] Unit 1 (파일럿 1대)
[5·6주] Unit 2 (서버)
[7주]  부품 도착 대기·매핑표 설계
[8~10주] Unit 3 (16대 조립+설치)
[11~14주] Unit 4 (운영 정착 + 첫 월간 리포트)
[15·16주] 발표·인계
```

자세한 일정과 평가 루브릭은 [교사용 통합 지도서](/climate-action-365/teacher/지도서/)를 참고하세요.

## 누구를 위한 자료인가

- **정보교사·환경교사**: 한 학기 수업 또는 동아리 활동으로 그대로 사용
- **학생 동아리**: 페어 워크 + 표준 절차로 자력 운영
- **다른 학교**: `secrets.py`의 SSID·서버 IP만 바꿔 이식 가능
